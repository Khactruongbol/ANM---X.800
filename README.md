# Đề tài 2 - X.800 Web Security Mapping

Repo này chứa giao diện website tin tức và bộ khung triển khai đồ án An ninh mạng theo kiến trúc X.800.

## Nội dung được đưa lên GitHub

- `app/website-tin-tuc/`: toàn bộ source giao diện và backend website tin tức.
- `app/`, `config/`, `certs/`, `database/`, `logs/`, `evidence/`, `scripts/`, `reports/`: bộ khung thư mục phục vụ triển khai, kiểm thử và lưu bằng chứng.
- `docs/Workflow đề tài 2.md`: workflow chính của đồ án.

## Nội dung không đưa lên GitHub

Các tài liệu nháp, prompt AI, phase implementation chi tiết và tài liệu tham khảo cục bộ không được track trong repo này. Phần `docs` chỉ giữ workflow chính theo yêu cầu.

## Mục tiêu đồ án

Xây dựng và kiểm thử một hệ thống Web có đăng nhập nhiều lớp bảo vệ, sau đó ánh xạ các tình huống tấn công theo kiến trúc X.800:

- Tấn công thụ động/chủ động.
- Dịch vụ bảo mật cần có.
- Cơ chế bảo mật triển khai.
- Bằng chứng kiểm thử.
- Giới hạn của từng cơ chế.

## Công nghệ nền

- PHP.
- MySQL/MariaDB.
- HTML/CSS/JavaScript.
- Apache/XAMPP hoặc Nginx.
- OpenSSL.
- Wireshark.
- curl/Postman.
